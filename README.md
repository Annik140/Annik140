## My GitHub Overview:

### Transparent Fashion | Bachelor Project
<!--
**[uis-bachelor-sustainability-webapp](https://github.com/Annik140/uis-bachelor-sustainability-webapp)**
-->
A full-stack web application exploring how publicly available sustainability reports can be used to calculate and compare sustainability scores for clothing brands.

The project grew out of an interest in the environmental impact of fast fashion and a curiosity about how sustainability can be measured. It was an opportunity to experiment with scoring methods, examine how brands report their sustainability efforts, and gain practical experience developing a full-stack application.

### Plantlog | Exam Project
<!--
**[plantlog-exam-project](https://github.com/Annik140/plantlog-exam-project)**
-->
A full-stack web application for managing personal plant collections and tracking watering history. Users can create accounts, manage their plants, record watering activity, and search or sort their collections.

This was my first solo web application. It includes basic user authentication, CRUD operations, watering records, and features a logo and icon I designed and illustrated myself.
